# UK Rail Viz — UI Design Spec

**Date:** 2026-08-02
**Status:** Draft
**Reference:** [MBTA Viz](https://mbtaviz.github.io/) — exact visual emulation

## 1. Purpose

Define the visual design system for the UK Rail Viz dashboard, emulating the MBTA Viz site's aesthetic exactly. The goal is a timeless, authoritative, data-dense dashboard that feels like a professional transit intelligence tool — not a modern "slick" web app.

## 2. Design Principles

- **Data-first**: Visualizations dominate the viewport; chrome is minimal.
- **Dark theme**: Deep navy background with amber accents — reads as "operations center."
- **SVG-first**: All visualizations render as inline SVG; no canvas, no raster.
- **Zero dependencies at runtime**: No D3, jQuery, Bootstrap, or any JS library in the browser.
- **Timeless over trendy**: The MBTA Viz aesthetic has aged well because it's functional, not fashionable. We follow that lead.

## 3. Color Palette

All colors are CSS custom properties in `:root`.

| Token | Value | Usage |
|---|---|---|

| `--panel` | `#132236` | Card/slot background |
| `--ink` | `#e8eef4` | Primary text |
| `--muted` | `#7a8fa3` | Secondary text, axis labels, grid |
| `--accent` | `#ffb400` | Section headings, highlights, active states |
| `--line` | `#2a3a4a` | Borders, grid lines, dividers |
| `--red` | `#ef4444` | Late/alert states |
| `--green` | `#22c55e` | On-time states |

## 4. Typography

- **Font stack**: `-apple-system, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`
- **Base**: `16px / 1.5` on `html, body`
- **Section headings (`h2`)**: `1.3rem`, `--accent` color, weight 600
- **Panel titles**: `0.95rem`, `--accent` color
- **Axis/station labels**: `11px`, `--muted` color
- **Tooltips**: `0.8rem`, `1.35` line-height
- **Status text**: `0.85rem`, `--muted` color

## 6. Layout

- Single long HTML page, one `<section>` per visualization with anchor IDs.
- `max-width: 64rem` centered container with `margin: 0 auto`.
- Sections separated by `1px solid var(--line)` border-bottom.
- Section padding: `1.75rem 0`.
- Each section has an `<h2>` title and optional `.viz-note` description.
- SVG visualizations fill full container width (`width: 100%`).

## 7. SVG Visualization Styles

### General
- All SVGs use `viewBox` for responsive scaling, no fixed width/height.
- Grid lines: `stroke: var(--line)`, `stroke-width: 0.5`
- Axis labels: `fill: var(--muted)`, `font-size: 11px`
- Station labels: `fill: var(--muted)`, `font-size: 11px`, right-aligned

### Marey Chart (The Trains)
- Trajectory paths: `stroke-width: 1.4`, `opacity: 0.75`, color per line
- Trajectory dots: `r: 1.8`, fill per line color
- Selected trajectory: `opacity: 1`, `stroke-width: 2.6`
- Dimmed trajectories (hover): `opacity: 0.15`
- Grid lines: `stroke: var(--line)`, `stroke-width: 0.5`
- Time axis labels at hourly intervals
- Station labels on the y-axis

### The People (Heatmap) — deferred until data available
- Heat cells: `height: 16px`, `border-radius: 2px`
- Active cell: `outline: 1px solid var(--ink)`, `outline-offset: 1px`
- Heat ramp: `hsl(215, 60%, 22%)` → `hsl(45, 95%, 60%)`

### Congestion & Delay (Horizon Charts) — deferred until data available
- Horizon areas: `mix-blend-mode: multiply`
- Delay band: `opacity: 0.85`
- Scrub line: `stroke: var(--accent)`, `stroke-width: 2`

### Live Overlay — deferred until data available
- On-time dots: `fill: var(--green)`
- Late dots: `fill: var(--red)`
- Labels: `fill: var(--ink)`, `font-size: 9`

## 8. Interaction Patterns

- **Delegated events**: Mouse events on parent `<g>` or wrapper `<div>`, not per-element.
- **Hover**: Pure CSS class toggles. `.highlight-active` dims non-selected items via `opacity`.
- **Tooltip**: Absolute-positioned `<div>`, dark background (`#0b1219`), amber strong text, `pointer-events: none`, `z-index: 5`.
- **Click**: Toggle `.active` class for cross-section highlighting (e.g., click a station in the heatmap → highlight in the table and map).
- **No jQuery, no D3 v3**: All interactions use vanilla DOM APIs and SVG DOM methods.

## 9. Deferred Sections

The following sections are registered in `sections.js` but will not render until their data files are available:

- **The People** (station traffic heatmap, table, map) — needs `station-frequency.json`
- **Your Commute** (per-origin percentile scatter) — needs `commute-*.json` files
- **Congestion & Delay** (horizon charts) — needs `delay.json`
- **Live Overlay** (train positions, status) — needs `live.json` + `live-delta.json`

These sections already have working renderers in the source code; they just need their data to be present.

## 10. Implementation Notes

- **Color values** are approximate based on the reference architecture spec; exact MBTA Viz values should be verified by auditing the live site during implementation.
- **No `box-shadow`** — MBTA Viz uses flat surfaces with no depth shadows.
- **Axis label font size** — `11px` aligns with MBTA Viz's 10px–11px range.
- **Current CSS migration** — the existing `src/styles/main.css` uses slightly different values (`--bg: #0f1720` vs `--bg: #0a1628`). The implementation should replace the current CSS with the design system defined here.
